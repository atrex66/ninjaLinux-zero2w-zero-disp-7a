# Ninja boot-logo example / Ninja bootlogó-minta

Derived from the user-provided `hardware/ninja.svg` artwork. Original paths
and their cutouts are preserved; paths use solid white fill without strokes,
centered on a black 1024×600 canvas. No additional wordmark or text is added.
The original hardware-project file is unchanged.

A felhasználó `hardware/ninja.svg` grafikájából készült. Az eredeti kontúrok
és kivágások megmaradtak; fehér kitöltés, körvonal nélkül, fekete 1024×600
vásznon középre igazítva. Az eredeti hardware-fájl változatlan.
